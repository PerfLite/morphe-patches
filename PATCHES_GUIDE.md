# 📋 Полное руководство по патчам Morphe (YouTube)

В этом файле описаны все доступные патчи, их назначение и рекомендации по включению/отключению.

---

## 🔴 КРИТИЧЕСКИЕ ПАТЧИ (НЕ ОТКЛЮЧАТЬ!)
> [!CAUTION]
> Отключение любого из этих патчей приведет к вылету приложения при запуске, невозможности воспроизведения видео или возвращению назойливой рекламы.

| Патч | Назначение |
|---|---|
| **`GmsCore support`** | Обеспечивает работу YouTube без Root-прав через MicroG / GmsCore. Без него приложение вылетает при старте. |
| **`Spoof video streams`** | Обходит защиту Google от сторонних клиентов и устраняет вечную буферизацию/зависание видео через 30-60 секунд. |
| **`Remove background playback restrictions`** | Снимает ограничения на фоновое воспроизведение (работает при выключенном экране и сворачивании). |
| **`Hide ads`** | Блокирует всю видеорекламу, баннеры, спонсорские плашки и промо-акции. |
| **`Voice over translation`** | Модуль закадрового перевода видео и нейросетевого дубляжа (Яндекс, Microsoft Edge TTS, Google Translate). |

---

## 🟡 ТОПОВЫЕ ПАТЧИ (Рекомендуется оставить)
> [!TIP]
> Основной функционал, ради которого используют модифицированный YouTube. Их можно отключать индивидуально, если конкретная функция вам не нужна.

| Патч | Назначение |
|---|---|
| **`SponsorBlock`** | Автоматически пропускает встроенную рекламу, интеграции букмекеров, самопиар блогеров и заставки внутри видео. |
| **`Return YouTube Dislike`** | Возвращает отображение реального счётчика дизлайков под видео. |
| **`Swipe controls`** | Регулировка громкости и яркости жестами свайпа по левой и правой части экрана. |
| **`Video quality`** | Запоминает выбранное качество видео (всегда запускает в 1080p/4K по Wi-Fi). |
| **`Playback speed`** | Расширенная настройка скорости воспроизведения (от 0.1x до 8.0x с гибким шагом). |
| **`Theme`** | Глубокая чисто-чёрная AMOLED тема оформления (экономит заряд экрана). |
| **`Open Shorts in regular player`** | Открывает Shorts в обычном плеере с перемоткой и кнопкой перевода. |
| **`Downloads`** | Добавляет кнопку для скачивания видео через внешние загрузчики (Seal, NewPipe, YTDL). |
| **`Sanitize sharing links`** | Очищает ссылки при нажатии «Поделиться» от трекеров и мусора (`?si=...`). |
| **`Seekbar`** | Тонкая настройка полосы перемотки (перемотка тапом, отключение задержек). |

## 🟢 ВИЗУАЛЬНЫЕ И ОПЦИОНАЛЬНЫЕ ПАТЧИ (Можно смело отключать)
> [!NOTE]
> Декоративные и вспомогательные настройки интерфейса.

| Патч | Назначение |
|---|---|
| **`Alternative thumbnails`** | Заменяет кликбейтные превью видео на реальные кадры через сервис DeArrow. |
| **`Ambient mode`** | Настройка фоновой динамической подсветки вокруг плеера. |
| **`Change start page`** | Позволяет открывать приложение сразу на Подписках вместо Главной страницы. |
| **`Custom branding`** | Изменяет иконку и отображаемое имя приложения на рабочем столе. |
| **`Custom player overlay opacity`** | Регулировка степени затемнения фона под элементами управления в плеере. |
| **`Disable DRC audio`** | Отключает компрессию динамического диапазона звука. |
| **`Disable Shorts resuming on startup`** | Предотвращает автоматический запуск Shorts при открытии приложения. |
| **`Disable rolling number animations`** | Отключает анимацию крутящихся счетчиков просмотров и лайков. |
| **`Disable haptic feedback`** | Отключает вибрационный отклик при действиях в плеере. |
| **`Double tap to seek`** | Дополнительные варианты времени перемотки по двойному тапу (5с, 15с, 30с...). |
| **`Hide Shorts components`** | Позволяет полностью скрыть раздел Shorts из ленты, поиска и каналов. |
| **`Hide player overlay buttons`** | Скрывает ненужные кнопки с экрана плеера (Трансляция, Автовоспроизведение и др.). |
| **`Hide end screen cards`** | Убирает всплывающие плашки рекомендованных видео в конце ролика. |
| **`Loop video`** | Добавляет кнопку зацикливания текущего видео. |
| **`Copy video link`** | Кнопка быстрого копирования ссылки на видео прямо в плеере. |
| **`Miniplayer`** | Выбор стиля свернутого окошка видео при переходе по приложению. |
| **`Navigation bar`** | Настройка и скрытие вкладок на нижней панели навигации. |
| **`Wide search bar`** | Широкая строка поиска в шапке на главной странице. |
| **`Remove viewer discretion dialog`** | Автоматически принимает предупреждение о возрастном ограничении 18+. |
